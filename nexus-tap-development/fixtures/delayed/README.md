# Delayed TAP fixture

This repository-owned fixture models a delayed path with distinct schedule and follow-up vertices. The Move package stores the scheduled value and applies it only in the follow-up call. `artifacts/delayed.dag.json` binds the occurrence edge and completed output, while `artifacts/delayed.skill.tap.json` binds both fixed Tools, the delayed policy, input commitment, and interface revision. `Move.toml` declares repository-relative `MoveStdlib` and `Sui` template dependencies; [dependency-template.json](dependency-template.json) pins the public `MystenLabs/sui` revision/checksum and documents the deterministic replacement with authenticated framework packages in the disposable consumer. [fixture-contract.json](fixture-contract.json) records two success tests and two expected-failure branches: `schedule` rejects inputs above 99 with abort code 0, and `execute` rejects a tampered scheduled state with abort code 1. The forward checker validates this contract, replaces only the template framework packages, and builds/tests the rewritten fixture in isolation; a structural schedule record does not claim that a follow-up executed on a live network.
