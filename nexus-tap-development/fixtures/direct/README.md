# Direct TAP fixture

This repository-owned fixture models one direct Tool path: the Move package creates a state value and executes it in one call. `artifacts/direct.dag.json` binds the `direct.fixture.execute@1` Tool and `artifacts/direct.skill.tap.json` binds its input commitment, policies, fixed Tool, and interface revision. `Move.toml` declares repository-relative `MoveStdlib` and `Sui` template dependencies; [dependency-template.json](dependency-template.json) pins the public `MystenLabs/sui` revision/checksum and documents the deterministic replacement with authenticated framework packages in the disposable consumer. [fixture-contract.json](fixture-contract.json) records two success tests and two expected-failure branches: `begin` and `execute` reject inputs above 99 with abort codes 0 and 1. The forward checker validates this contract, replaces only the template framework packages, and builds/tests the rewritten fixture in isolation.
